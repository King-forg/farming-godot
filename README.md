You currently spawn in the debug world. If you press F for menu, and click the person icon, it will take you to the main map where the majority of the new features will be in.

Includes:
 - Collision
 - Tile based rendering
 - GUI
 - Pause Menu with buttons
 - Directional character movement
 - Randomly moving animals
 - Animated player and animals
 - Music
 - Textures that work well
 - Custom house
 - Collisions on new map
 - SFX for footsteps
 - footsteps change speed based on speed of player

I basically made this because I wanted to be able to made a large scale project. For example, a game.
The goal for this game is to be able to be a game where you farm crops and things while following along with a story of some kind. However this isn't final.
The name is still wip so if you have any ideas for a name, you can dm me on slack or discord. @kingforg for both.

I created this using godot and also used the assets from the credits in credit.txt.
